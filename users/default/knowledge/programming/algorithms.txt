Algorithms

An algorithm is a clear set of steps for solving a problem. A recipe is a familiar example: it tells you what to do and in which order. A computer algorithm must describe steps precisely enough for a computer to follow.

Procedure: To find a number in a list using linear search:
Step 1: look at the first number.
Step 2: compare it with the number you want. If they match, you have found it.
Step 3: if not, try the next number. Stop when you find it or reach the end of the list.

Binary search finds a value in a sorted list by checking the middle and discarding the half that cannot contain it. Repeating this makes the remaining search range smaller. The list must be sorted first.
