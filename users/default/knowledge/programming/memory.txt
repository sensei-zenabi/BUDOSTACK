Computer memory and variables

Computer memory holds information a computer is using. Random-access memory (RAM) is working memory: it keeps data ready while a program runs. Most RAM loses its contents when the power turns off.

Simple explanation: Computer memory lets a computer remember things by storing data in locations with addresses. An address is like a numbered box: the computer uses the number to find the data again. Memory does not think or remember like a person.

A variable is a name a program uses to store or refer to a value. Think of a labelled box: score might hold the number 10. The value can change while the program runs.

Persistent storage keeps information when power is off. A saved file on a drive is an example. Volatile memory needs power to keep its data; most working RAM is volatile.
